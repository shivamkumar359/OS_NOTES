Operating Systems

Fingertip Concise Exam Notes

1. What is an Operating System?

Operating System (OS): Software that acts as an intermediary between the user and computer hardware.

ViewMeaning
User-centricProvides an easy interface and services to users
System-centricAllocates resources and controls system operations
Exam Point OS = Resource Allocator + Control Program + Interface

2. Computer System Structure

A computer system has 4 main components:

  • Hardware: CPU, memory, I/O devices
  • Operating System: Controls and coordinates hardware
  • Application Programs: Word processors, browsers, compilers, DBMS, games
  • Users: People, machines, other computers
Hardware → OS → Applications → Users

3. What Does an OS Do?

Depends on the system type:

  • Provides convenience & improves performance
  • Manages system resources & supports multiple users/programs
  • Optimizes battery life in handheld systems
  • Embedded systems may have little or no user interface

4. Computer Startup

Bootstrap Program → Initializes System → Loads OS Kernel → Starts Execution

Bootstrap Program

  • Stored in ROM/EPROM (firmware)
  • Loads the OS kernel into memory
Exam Bootstrap program is the first program executed during startup.

5. Computer-System Operation

  • CPU and I/O devices work concurrently.
  • Each device has a device controller with a local buffer.
  • Data moves between main memory ↔ local buffer.
  • Controller triggers an interrupt to CPU upon completing an operation.
Device → Controller → Buffer → Memory → Interrupt

6. Storage Hierarchy

Organized as a hierarchy based on three primary vectors:

  • Speed
  • Cost
  • Volatility

Rule of Thumb: Faster storage is generally more expensive, volatile, and smaller in capacity.

7. Caching

Definition: Copying information from slower storage to faster storage temporarily.

  1. Check faster storage (cache).
  2. If data present → use it directly (Hit).
  3. If absent → copy data from slower storage to cache (Miss).
  4. Use cached copy.

Key Issues: Cache size, replacement policy, and cache management.

Cache = Small + Fast + Temporary copy

8. Device Driver

Definition: Software that manages a particular device controller.

  • Directly controls and manages specific I/O devices.
  • Provides a uniform interface between device controllers and the OS kernel.

11 & 12. Operations & Dual-Mode Protection

OS operation is interrupt-driven:

  • Hardware Interrupt: Generated by hardware devices via system bus.
  • Software Interrupt (Trap/Exception): Generated by software errors (e.g., division by zero) or requests for OS services.

Dual-Mode Operation

Protected by hardware Mode Bit (User Mode vs. Kernel Mode).

User Program → System Call → Switch to Kernel Mode → Service → Return to User Mode
Exam Privileged instructions cannot be executed directly in user mode.

13 & 14. Process Management

Process: A program in execution.

ProgramProcess
Passive entity (stored binary/code)Active entity (executing in memory)
No dynamic execution stateMaintains registers, PC, heap, and stack

OS Process Activities: Creation, deletion, suspension, resumption, synchronization, communication, and deadlock handling.

15, 16 & 17. Memory, Storage & I/O Subsystems

  • Memory Management: Tracks free/used memory; allocates and deallocates dynamic space for instructions/data.
  • File-System: Maps logical file views to physical storage; organizes directories and manages access control.
  • I/O Subsystem: Hides device complexities using:
    • Buffering: Temporary storage holding data during transfers.
    • Caching: Storing active data in faster memory for immediate performance.
    • Spooling: Overlapping output of one job with input of another (e.g., print spooling).
Buffer = Temp Transfer | Cache = Faster Copy | Spool = Overlap I/O

18. Protection & Security

  • Protection: Internal mechanism controlling processes/users access to system resources.
  • Security: External defense against threats (viruses, worms, DoS, identity theft).
  • Access Control: Enforced via User IDs and Group IDs associated with running processes.
Exam Protection = Access Control • Security = Defense against attacks

19, 20 & 21. Interfaces & System Calls

User Interfaces: CLI (command shells), GUI (visual windows/icons), Touchscreen interfaces.

System Call: Programming interface used to request services from the OS kernel (invoked via standard APIs like POSIX, Windows API, Java API).

23–26. Modern OS in AI, Data Science & MLOps

  • Process & Thread Schedulers: Dictate CPU-GPU overlap, training latency, and batch scheduling.
  • Memory Subsystems: Prevent swapping and fragmentation on huge models; leverage mmap() for huge datasets and batch prefetching.
  • Accelerators: Manages GPU kernel drivers, DMA transfers, and NUMA-aware memory topologies.
  • Distributed Networking: OS handles low-latency RDMA, RoCE, and kernel-bypass for distributed All-Reduce gradients.
  • Containers: Utilizes Linux Namespaces (isolation) and cgroups (CPU/memory/GPU resource limits).

Exam One-Liners & Quick Facts

  1. OS: Software acting as an interface between user and hardware.
  2. Resource Allocator: Allocates CPU, memory, and devices efficiently.
  3. Control Program: Prevents errors and improper computer usage.
  4. Process: A program in active execution with associated resources.
  5. Multiprogramming: Keeps multiple jobs in memory to prevent CPU idling.
  6. Timesharing: Rapid CPU switching to create interactive multi-user sessions.
  7. Interrupt: Asynchronous signal notifying the CPU of an event.
  8. Kernel Mode: Mode bit 0; allows privileged instructions to execute.
  9. User Mode: Mode bit 1; restricted sandbox for safe user program execution.
  10. System Call: Software request bridge for kernel routines.
  11. Device Driver: Translation layer between device controller and OS.
  12. Caching: Storing slow-storage data in smaller, faster memory blocks.
  13. Protection vs Security: Protection controls internal access; Security defends against external/internal attacks.

⚡ 15-Second Summary

An OS provides an interface between users and hardware while managing core system resources. Responsibilities span processes, memory, storage, I/O, protection, and security. Multiprogramming maximizes CPU utilization; timesharing enables interactive computing. Interrupts drive asynchronous processing, and dual-mode operation safeguards hardware. Modern workloads (AI/ML) rely heavily on kernel scheduling, batch prefetching, low-latency RDMA, and container control groups (cgroups).
